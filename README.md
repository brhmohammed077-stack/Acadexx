# ACADEX / Amirdesign static website

ملفات موقع ثابت يمكن نشرها على GitHub Pages، بلا تثبيت أدوات.

## الملفات
- `index.html`: الأسعار ومعرض الأعمال
- `order.html`: نموذج الطلب المستقل
- `track.html`: صفحة التتبع
- `templates.html`: متجر القوالب الجاهزة
- `styles.css`, `script.js`: التصميم والتفاعلات
- `assets/acadex-logo.jpg`: شعار ACADEX

## مهم قبل النشر
1. معرض الصور يستخدم مربعات تجريبية؛ استبدلها بصور أعمالك الحقيقية والفيديوهات من خلال تحديث `script.js` وملفات الصفحة.
2. نموذج الطلب يجهز رسالة `mailto` ويفتح تطبيق البريد على جهاز العميل. لا يرسل تلقائيًا ولا يخزن طلبات في قاعدة بيانات.
3. التتبع مجرد واجهة حتى يتم ربطه بقاعدة بيانات أو خدمة خلفية.
4. التحقق من صيغة البريد/الهاتف في المتصفح لا يثبت ملكية البريد أو رقم الهاتف. التحقق برمز OTP يحتاج مزودًا خلفيًا.
5. لا يوجد أي بريد شخصي ظاهر في ملفات الواجهة. لتلقي الطلبات تلقائيًا، اربط خدمة نماذج من جهة الخادم؛ لا تضع مفاتيح سرية أو بيانات خاصة في ملفات الواجهة.
6. الأسعار الحالية عينة قابلة للتعديل وليست تأكيدًا لأسعارك النهائية.

## النشر من الهاتف
ارفع جميع الملفات ومجلد `assets` إلى جذر مستودع GitHub، مع إبقاء `index.html` في الجذر. ثم فعّل GitHub Pages من Settings → Pages واختر `Deploy from a branch` ثم `main` و`/(root)`.
